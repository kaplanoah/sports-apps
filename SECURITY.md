# Security policy

## Supported versions

The latest production version of each app and service.

Security fixes are maintained on `main`.

## Reporting a vulnerability

This repository is public. Report vulnerabilities or exposed secrets through [GitHub's vulnerability reporting form](https://github.com/kaplanoah/sports-apps/security/advisories/new).

Please do not open a public issue or pull request for a vulnerability.

Include the app or service affected, its version or commit if known, the steps to reproduce, and what an attacker could do.

I will reply within 7 days, and confirm when a fix is live.
If you'd like public credit, please tell me in the report.
